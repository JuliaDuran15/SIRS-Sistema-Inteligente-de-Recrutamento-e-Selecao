════════════════════════════════════════════════════════════════
 ERROS / LIMITAÇÕES CONHECIDAS DA INTERFACE
════════════════════════════════════════════════════════════════

  1. Currículo em texto — sem campo na UI
     O formulário de candidato não tem campo "texto do currículo".
     Só é possível enviar PDF. Para testar sem PDF, use o curl:
       curl -X POST .../candidaturas/{id}/curriculo/texto
       -d '{"texto": "..."}'

  2. Formação do candidato — sem campo na UI
     O formulário "Novo Candidato" não tem seção de formação
     acadêmica (curso/instituição). Precisa de curl para preencher.

  3. editarAnotacoes (PATCH /entrevistas/{id}/anotacoes)
     O endpoint existe no backend mas não há botão separado na UI.
     A edição completa do resultado (score + anotações + pontos)
     via "Editar resultado" já salva o histórico de edições.
